# IllustBlend

배경과 인물 레이어를 쌓고, **원본 그림은 그대로 둔 채 필터 층만 얹어** 둘이 자연스럽게 어우러지게 하는 합성 도구입니다.

- **웹 / 아이패드**: https://sawa1023.github.io/illustblend/  
  아이패드 Safari에서 열고 공유 → **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. 한 번 연 뒤에는 인터넷 없이도 열립니다.
- **Windows 프로그램**: [Releases](../../releases)에서 `IllustBlend-*.exe`를 받아 실행하세요. 서명되지 않은 프로그램이라 처음에 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

## 주요 기능
- 레이어 추가, 이미지 끌어 놓기/열기, 레이어마다 인물·배경·일반 지정
- 캔버스 크기 직접 지정, 8개 핸들로 크기 조절 (Shift 또는 '비율 고정'으로 비율 유지)
- 인물·배경·전체 화면별 기본 보정 (밝기, 대비, 채도, 색조, 노출, 감마, 흐림)
- 조명: 빛 세기, 역광 그림자, 테두리 빛, 8방향 빛 방향
- 컬러 프리셋 겹치기, 효과 20종 (글리치, 노이즈, 색수차, 블룸, 빛줄기, 비네팅 등)
- 배경에 자동 맞춤, 빠른 느낌 9종, 내 프리셋 저장
- 보정 전/후 비교 (F키), PNG 내보내기

이미지는 모두 브라우저 안에서만 처리되고 어디에도 업로드되지 않습니다.
